- New: OpenAI Codex works with Agentville too. In Settings, click "Connect Codex", then trust the hook once in Codex (/hooks, or Settings → Hooks in the Codex app). Codex sessions walk in as their own characters next to Claude Code ones, tagged CX and CC.
- New: every piece of clothing can come off — top, bottoms and shoes have "None". Hats, glasses and scarves are now separate slots, so you can wear them together; glasses and sunglasses you already wear move to the new glasses slot.
- Fixed: the character editor scrolls when the window is short, instead of cutting off the Save button.
- Fixed: two sessions in the same project no longer look identical; the second one gets its own look, which you can change on its own.
- Fixed: Settings shows a green "All set" once Agentville has seen your sessions, instead of staying orange after every launch.

- 新增：支援 OpenAI Codex。在設定中按「連接 Codex」，再到 Codex 信任這個 hook 一次（/hooks，或 Codex App 的設定 → Hooks）。Codex 的工作階段會以獨立角色進入辦公室，跟 Claude Code 的角色並排，並以 CX、CC 標示區分。
- 新增：所有服裝都可以脫掉，上衣、下著、鞋子都有「不穿」。帽子、眼鏡、圍巾分成不同欄位，可以同時穿戴；原本戴著的眼鏡和墨鏡會自動移到新的眼鏡欄位。
- 修正：視窗較矮時，角色編輯器可以捲動，「儲存」按鈕不會再被切掉。
- 修正：同一個專案的兩個工作階段不會再長得一模一樣；第二個會有自己的外觀，也可以單獨修改。
- 修正：只要 Agentville 看過你的工作階段，設定頁就會顯示綠色的「設定完成」，不會每次開啟都停在橘色。
